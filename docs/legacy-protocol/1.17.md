# Bedrock Edition 1.17 legacy support

## Stable profile matrix

| Stable client releases | Protocol | Profile | Live test |
| --- | ---: | --- | --- |
| 1.17.0, 1.17.1, 1.17.2 | 440 | `1.17.0` | 1.17.2 joined and played |
| 1.17.10, 1.17.11 | 448 | `1.17.10` | 1.17.11 joined and played |
| 1.17.30, 1.17.32, 1.17.33, 1.17.34 | 465 | `1.17.30` | 1.17.34 joined and played |
| 1.17.40, 1.17.41 | 471 | `1.17.40` | 1.17.41 joined and played |

1.17.20 was a preview, not a stable release. Unlisted preview protocols are out of scope. Clients sharing a protocol ID share the same wire profile.

## Release status

All four profiles are admitted in `ACCEPTED_PROTOCOL`. The owner verified each representative client on a localhost test server with Xbox authentication: join and spawn, chunk loading, movement, block breaking and drops (creative and survival), flight and commands. The test gate and the spawn/disconnect diagnostics used during development were removed for the release.

## Implementation notes

- Byte-for-byte historical canonical block-state and required-item snapshots are restored in BedrockData for all four profiles. The 1.17.40 palette is the unversioned historical 1.17.40 canonical palette.
- Packet boundaries restored from preserved PocketMine history include 1.17.0 versus 1.17.10 resource-pack/command/title fields, 1.17.30 education/volume/animation/crafting/hurt-armor/actor-pick/photo fields, 1.17.40 sub-chunk response, and the 1.18.0 StartGame checksum and sub-chunk hash field.
- Skins before 1.17.30 have no geometry engine version, and the premium/persona/cape-on-classic flags follow the animation data (no primary-user flag). Sending the 1.17.30 layout to 440/448 crashed the client after spawn.
- Pre-1.18 chunks use the old overworld height and two-dimensional biomes; zero-bit palettes are expanded for 440/448 and natively encoded from 465 onward. The sound ID is clamped to the historical 1.17 `UNDEFINED` ID 330.
- StartGame advertises movement mode 1 (server-authoritative with `PlayerAuthInputPacket`); wire value 2 means rewind-based movement to 1.17 and stalls before spawn. Server-authoritative block breaking is off, so 1.17 clients report destroyed blocks through the `BREAK_BLOCK` item interaction, which the server applies via `Player::breakBlock()`.
- `PlayerAuthInputPacket` carries flag-gated interaction data (the complete legacy `UseItemTransactionData`), item stack request and block actions. 1.17 stack-request action IDs 14/15 are the deprecated crafting actions.
- Clients below 1.19.10 (1.17 and 1.18) receive abilities, permissions and auto jump through `AdventureSettingsPacket`; clients below 1.19.0 report flight changes through the same packet.
- The `locatorbar` game rule is only sent from 1.21.80.

## Known gaps

- Historical block-item, block-state-meta and item-tag datasets are unavailable and use documented newer fallbacks. They are not proven version-accurate; rendering of rare blocks and tag-based recipes may differ.
- Recipes with tag ingredients cannot be expressed before 1.19.30 and are skipped.

Historical evidence: PocketMine-MP commits `57d274901`, `8b79253d3`, `8e2d06a88`, `c4446ca28`; BedrockProtocol commits `faff7da`, `ea9e225`, `040a883`; BedrockData tree `657395e^` and commit `f29b7be`. See `SOURCES.md` for upstream references. The Essential PocketMine-MP fork served as a working reference implementation for the skin layout, 1.17.30 field gates, legacy abilities and block breaking.
